# 과제 마감일 알리미 (공휴일 API 업데이트)

과제 이름과 마감일을 입력하면 남은 날짜를 `D-3`처럼 계산하고, 마감이 가까운 순서로 보여주는 프로그램입니다.
9주차 업데이트에서 **Nager.Date 공휴일 API**를 붙여, 마감까지 **실제로 쓸 수 있는 평일 수**와 **마감일이 주말·공휴일인지**를 함께 보여줍니다.

- 기존 기획: `plan-1 (1).md`
- 이번 API 기획: `api-plan.md`

## 1. 실행 방법

[uv](https://docs.astral.sh/uv/)가 설치되어 있으면 아래 명령만으로 실행됩니다. 필요한 파이썬 버전(3.14)과 라이브러리(`requests`)는 uv가 `pyproject.toml`과 `uv.lock`을 보고 자동으로 설치합니다.

```bash
git clone https://github.com/leothewonder/assignment_manager.git
cd assignment_manager
uv run assignment_manager.py          # 창(GUI) 모드
uv run assignment_manager.py --cli    # 콘솔(CLI) 모드
```

### API 키

**이 프로그램이 쓰는 Nager.Date API는 키가 필요 없습니다.** 따라서 `.env` 파일을 만들 필요가 없고, 클론 후 바로 실행됩니다.
(혹시 모를 실수를 막기 위해 `.gitignore`에는 `.env`를 넣어 두었습니다.)

인터넷 연결이 필요하지만, 연결이 안 되어도 과제 추가·삭제·D-day 기능은 그대로 동작합니다.

## 2. 새로 추가된 기능

| 기능 | 설명 |
|---|---|
| 남은 평일 | 오늘부터 마감일까지(마감일 포함) 토·일요일과 공휴일을 뺀 날 수 |
| 비고 | 마감일이 공휴일이면 공휴일 이름, 주말이면 `토요일`/`일요일` 표시 |
| 마감일 안내 | 과제를 추가할 때 마감일이 쉬는 날이면 "미리 끝내두라"는 안내 |
| 다가오는 공휴일 | 앞으로 60일 안의 공휴일 목록 (CLI 메뉴 4번, GUI "다가오는 공휴일" 버튼) |
| 공휴일 저장 | 받아온 공휴일을 `holidays_cache.json`에 저장하고 7일 동안 재사용 |

CLI 실행 예시:
```
 번호 | D-Day     | 평일  | 마감일     | 비고          | 과제 이름
------------------------------------------------------------------------------
 1    | D-5       | 5일   | 2026-11-07 | 토요일        | 주말 과제
 2    | D-53      | 38일  | 2026-12-25 | 기독탄신일    | 크리스마스 과제
```
D-53이지만 주말과 공휴일을 빼면 실제로 쓸 수 있는 평일은 38일이라는 뜻입니다.

## 4. 코드 설명

### 4-1. 전체 흐름

```
프로그램 시작
  → assignments.json에서 과제 목록 불러오기
  → 필요한 연도(올해, 내년, 과제 마감일의 연도) 계산
  → 연도마다: 7일 안에 받은 저장본이 있으면 사용, 없으면 API 호출
  → 표를 그릴 때 과제마다 D-day, 남은 평일, 비고 계산
  → 종료 시 과제 목록 저장
```

### 4-2. `holiday_api.py` (API 모듈)

**`fetch_holidays(year)` — API를 실제로 부르는 함수**
```python
response = requests.get(API_URL.format(year=year), timeout=TIMEOUT_SECONDS)
response.raise_for_status()
items = response.json()
```
- `https://date.nager.at/api/v3/PublicHolidays/2026/KR`처럼 연도를 넣은 주소로 요청을 보냅니다.
- `timeout=5`: 서버가 5초 안에 답하지 않으면 포기해서 프로그램이 멈춰 있지 않게 합니다.
- `raise_for_status()`: 서버가 404·500 같은 오류 코드를 보내면 예외를 일으킵니다.
- `response.json()`: 응답으로 온 JSON 글자를 파이썬 리스트로 바꿉니다.
- 응답 리스트에서 `date`와 `localName`(한국어 이름)만 뽑아 `{"2026-12-25": "기독탄신일"}` 형태의 딕셔너리로 만듭니다. 딕셔너리를 쓰면 "이 날짜가 공휴일인가?"를 `날짜 in holidays`로 바로 확인할 수 있습니다.
- 연결 실패, 오류 응답, 잘못된 JSON은 모두 `except`에서 잡아 `None`을 돌려줍니다. 그래서 인터넷이 없어도 프로그램이 꺼지지 않습니다.

**`load_holidays(years)` — 저장본과 API 중 무엇을 쓸지 정하는 함수**

연도마다 아래 순서로 판단하고, 결과와 함께 상태 문구를 돌려줍니다.

1. 7일 안에 받아온 저장본이 있다 → API를 부르지 않고 저장본 사용 (`최신 공휴일 정보`)
2. 없거나 오래됐다 → API 호출. 성공하면 `holidays_cache.json`에 저장
3. API 호출 실패 + 예전 저장본 있음 → 예전 저장본 사용 (`저장된 공휴일 정보 사용`)
4. API 호출 실패 + 저장본 없음 → 공휴일 없이 동작 (`공휴일 정보 없음`)

같은 정보를 매번 받아오지 않게 해서 실행이 빠르고 서버에도 부담을 주지 않습니다.

**`count_workdays(deadline, holidays)` — 남은 평일 수**

오늘부터 마감일까지 하루씩 넘기면서 `weekday() < 5`(월~금)이고 공휴일 딕셔너리에 없는 날만 셉니다. 마감이 지났으면 `"-"`를 돌려줍니다.

**`day_note(deadline, holidays)` — 비고 칸**

마감일이 공휴일이면 그 이름을, 아니면 `weekday()`가 5·6일 때 `토요일`/`일요일`을, 평일이면 빈 문자열을 돌려줍니다.

**`upcoming_holidays(holidays)`, `years_needed(assignments)`**

60일 안의 공휴일을 날짜순으로 모으는 함수와, 공휴일을 받아올 연도 목록(올해, 내년, 마감일의 연도)을 만드는 함수입니다.

### 4-3. `assignment_manager.py`에서 바뀐 부분

- **CLI**: 시작할 때 `load_holidays()`로 공휴일을 불러오고 상태를 안내합니다. 목록 표에 `평일`, `비고` 칸을 추가했고, 메뉴에 `4. 다가오는 공휴일 보기`를 넣어 종료는 5번이 됐습니다.
- **과제 추가**: `add_assignment()`가 추가한 마감일을 돌려주도록 바꿨습니다. 그 날짜로 `warn_if_day_off()`를 불러 쉬는 날이면 안내합니다. 새 마감일이 다른 연도일 수 있어 추가 후 `load_holidays()`를 다시 부르지만, 저장본이 있으면 API는 호출되지 않습니다.
- **GUI**: 표에 `남은 평일`, `비고` 열을 추가하고, 아래쪽 상태 표시에 공휴일 정보 상태를 함께 보여줍니다. 마감일 안내와 다가오는 공휴일은 팝업 창으로 보여줍니다.

## 5. 한계

- Nager.Date는 해외 서비스라 선거일 같은 **임시공휴일이 늦게 반영되거나 빠질 수 있습니다.**
- 학교 휴강일이나 시험 기간은 반영하지 않습니다.
